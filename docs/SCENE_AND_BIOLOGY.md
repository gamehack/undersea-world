# 场景与海洋生态规则

## 已实现的场景底层

- 连续浅海珊瑚礁区域，约 60m × 60m，可潜范围 -16m 至 1.4m。
- 沙/岩海床、46 个程序化礁石、76 个程序化珊瑚簇；确定性随机种子便于复现。
- 三种珊瑚形态：分枝、盘状、块状；色彩克制，不使用幻想霓虹效果。
- WebGL 雾化水体、半透明水面、方向光和低成本光束，随画质等级调整。

## 首版已实现的生态行为

- 三类程序化礁鱼：蓝色鱼群（16 条）、黄色鱼群（12 条）和条纹鱼群（6 条），共 34 条。
- 每类鱼有独立的体长、配色、活动水深和速度；同类间进行邻近避让、方向协调与边界回避，尾鳍周期摆动。持续巡游驱动力避免鱼群受阻尼影响在数十秒后停止。
- 一只程序化海龟：沿平缓水中轨迹巡游，具备头部、背甲、腹部及双鳍，双鳍周期摆动。
- 固定随机种子生成；后台恢复后单步时间上限为 50ms，避免突移。
- 为减少移动端计算开销，鱼的方向修正交错逐帧更新。尚未实现真实物种级骨骼动画或远距网格 LOD。
- 禁止氧气倒计时、伤害、捕猎与不合理的鲸鱼浅滩活动。

以上现阶段是**程序化视觉母版**，三种鱼的颜色分组不是经过专业海洋生物学核验的物种名称。发布前需审查物种名称和栖息地描述。
