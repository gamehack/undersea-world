# 产品需求与状态

**已批准方向：** 真实海洋模拟 A、Three.js + WebGL 2 方案 2、轻量生态写实 B。

首版以浏览器自由潜游一处热带珊瑚礁为目标；不做任务、等级、氧气、伤害、账号、付费、多人或 AI 聊天。手机与 PC 均可访问，音频默认静音。

## 当前实现

- 静态海洋介绍页与进入按钮。
- WebGL 2 能力检测：支持则继续下一阶段初始化；不支持则展示静态预览、错误原因与重试。
- 声音、画质和操作帮助的基础控件；进入后可加载程序化 3D 珊瑚礁并自由潜游。
- PC：WASD/方向键游动，空格上浮，Shift/C 下潜，拖动鼠标转视角。
- 手机：左侧触摸区拖动方向、右侧拖动视角、上浮/下潜按钮。
