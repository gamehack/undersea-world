# 产品需求与状态

**已批准方向：** 真实海洋模拟 A、Three.js + WebGL 2 方案 2、轻量生态写实 B。

首版以浏览器自由潜游一处热带珊瑚礁为目标；不做任务、等级、氧气、伤害、账号、付费、多人或 AI 聊天。手机与 PC 均可访问，音频默认静音。

## 当前实现

- 静态海洋介绍页与进入按钮。
- WebGL 2 能力检测：支持则继续下一阶段初始化；不支持则展示静态预览、错误原因与重试。
- 声音、画质和操作帮助的基础控件；进入后可加载程序化 3D 珊瑚礁并自由潜游。
- PC：WASD/方向键游动，空格上浮，Shift/C 下潜，拖动鼠标转视角。
- 手机：左侧触摸区拖动方向、右侧拖动视角，支持两手同时操作；上浮/下潜按钮独立控制。
- 海洋生物：34 条分属三类的程序化礁鱼、1 只自行巡游的海龟；无需用户触发、没有战斗或任务。
- 画质：“自动”根据设备内存与像素比决定低/中/高档，并在持续掉帧后逐级降档；也可手动覆盖。切换后场景重新加载，当前位置暂不保留，但会话时长和人工暂停状态保留。
- 帧率：在场景内显示最近一段时间估算的 FPS 和正在使用的画质档位。
- 生态与边界：用简化圆形代理推离珊瑚和礁石，靠近世界边界先柔和引导，最终仍限制于可探索范围。
- 水体颗粒：浅海中轻量漂浮；用户可单独关闭光束/颗粒而不改变其他画质内容。
- 声音：默认关闭。进入海洋后可主动开启本地合成的低音量水流声，暂停或切换到后台时自动挂起，退出时释放。
- 音量：设置面板以 0—100 滑杆控制环境音振幅；默认 40%，音量 0 等价静音输出。
- 舒适度：缓慢模式将游动和转向速度降到 45%，支持用户关闭水体动效；尊重系统减少动态效果偏好。
- 页面：设置集中于折叠菜单；潜游时可隐藏 HUD，并通过常驻“显示界面”按钮恢复。首次进入可跳过的操作提示，帮助按钮可再次打开。
- 生命周期：可暂停、继续、退出并返回首页。窗口失焦、切换到后台均停止动画与音频，回到前台后依原暂停意愿恢复。Esc 可暂停/继续。
- 恢复：WebGL 上下文丢失暂停画面并展示提示和重新连接入口；浏览器恢复上下文后可继续。
- 匿名事件：进入/退出、手动暂停、图形失败、画质和音量、活跃 3/10 分钟，不发送到外部服务。
