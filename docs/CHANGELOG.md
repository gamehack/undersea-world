# 变更记录

## 2026-11-11 · 开发起步

- 锁定轻量生态写实设计 V1.0。
- 建立静态首页、浏览器图形能力检测和可恢复的静态兜底。
- 建立最初的产品说明与测试构建命令。

下一阶段：实时珊瑚礁场景与水下光影。

## 2026-11-11 · 程序化珊瑚礁

- 新增连续海床、岩石、三类珊瑚形态、水下颜色雾化与低成本光束。
- 进入按钮可启动 Three.js 场景，目前为固定观察镜头；下一阶段实现移动与旋转。

## 2026-11-11 · 自由潜游控制

- 新增键鼠和触摸控制、上浮下潜、平滑速度与世界边界限制。
- 镜头由固定观察改为第一人称潜游；新增输入清理与速度测试。
- 尚未完成浏览器画面测试；当前受执行环境 Chromium 启动权限限制，不能将移动端视觉体验标为已通过。

## 2026-11-11 · 海洋生物自主运动

- 加入三类程序化珊瑚礁鱼共 34 条、1 只程序化海龟；根据邻近个体和活动区域缓慢运动。
- 为后台恢复的较大时间差设置步长上限，并修复海龟首次更新的轨迹跳变。
- 生态逻辑通过自动化单元测试；实际画面与移动端帧率仍待浏览器和设备验收。

## 2026-11-11 · 自适应画质与性能诊断

- 增加低/中/高实际渲染密度、自动档位选择及可切换的 UI；低画质显著削减动态鱼群、礁石、珊瑚及渲染像素数。
- 首页与 3D 引擎拆包，只有点击进入后才下载 Three.js。
- 增加近 120 帧 FPS 统计和小型帧率显示；真实性能目标列入 `docs/PERFORMANCE.md`，不虚报真机帧率。

## 2026-11-11 · 体验生命周期、声音与隐私事件

- 启用真实的进入/暂停/继续/退出状态；后台与 WebGL 丢失时暂停并支持恢复。
- 新增默认静音的本地水流音效，无需外部音乐授权，用户主动开启后才播放。
- 为进入/退出、画质、声音、异常和活跃 3/10 分钟提供匿名页面内事件；未连接统计服务。

## 2026-11-11 · 发布候选版验证准备

- 新增 Playwright PC/移动端自动验收用例及 GitHub Actions 单测/构建流水线；完整浏览器测试按需手动运行。
- 添加 QA 状态矩阵、Cloudflare Pages 静态部署说明和真机验收边界。
- 本地 Chromium 因系统级 socket 权限问题无法启动；浏览器画面与触摸真实体验保持未验收状态。

## 2026-11-11 · P0 代码审查修复

- 修复鱼群长时间阻尼减速为静止；增补长时巡游回归测试。
- 手机独立跟踪移动与视角触点，支持双指同时操作；按钮焦点保留空格激活、Esc 暂停。
- 活跃时长改用真实前台帧间隔而非模拟步长；切画质保留会话、里程碑与人工暂停。
- 后台与窗口失焦同时暂停动画/音频；自动画质在持续慢帧时逐级降档。
